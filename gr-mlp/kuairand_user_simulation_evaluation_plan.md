# KuaiRand 用户模拟与评估计划

## 1. 背景与目标

本计划用于评估在 KuaiRand 数据集上生成的用户模拟数据质量。用户模拟数据包含模拟用户画像、历史交互序列，以及在给定候选物品对时模拟用户对正负样本的偏好判断。

核心目标是建立一套从人工标注到模型化评估、再到全量数据自动评估的流程，最终得到全量模拟数据的准确率，并判断模拟数据质量是否达到 75% 的目标阈值。

## 2. 总体流程

整体流程分为三步：

1. 人工标注 1,000 条模拟样本，并计算指标 1：模拟的准确率。
2. 基于这 1,000 条标注数据微调一个 LLM 评估模型，使模型学习人工评估标准。
3. 使用第二步得到的 LLM 评估模型，对剩余模拟数据进行自动评估，计算指标 2：自动评估准确率，并判断是否达到 75%。

指标 1 和指标 2 共同构成全量模拟数据准确率的估计结果。

## 3. 数据定义

### 3.1 输入数据

每条模拟样本包含以下信息：

- 模拟用户画像。
- 模拟交互序列。
- 候选物品对：给定一对候选物品。
- 模拟判断结果：模拟用户在候选物品对上的偏好选择或正负样本判断。

### 3.2 标注输出

人工标注人员需要基于用户画像和交互序列，判断候选物品对中哪个物品更符合该用户的真实偏好，并给出：

- 正样本物品：更符合用户画像和历史行为的物品。
- 负样本物品：相对不符合用户画像和历史行为的物品。

## 4. 第一步：人工标注与指标 1

### 4.1 标注数据

从模拟数据中选出 1,000 条用户画像和交互序列。对每条样本，给定一对物品，由人工标注正样本和负样本。

### 4.2 人工标注

人工标注人员根据用户画像、交互序列和给定的一对物品，标注其中的正样本和负样本。

### 4.3 指标 1：模拟的准确率

指标 1 衡量 1,000 条人工标注数据上的模拟准确率。

定义：

```text
指标 1 = 人工标注集中模拟判断正确的样本数 / 1,000
```

其中：

- 模拟判断正确：模拟用户给出的正负样本判断与人工标注结果一致。
- 人工标注总样本数：1,000。

输出结果包括：

- 人工标注总样本数。
- 模拟判断正确样本数。
- 指标 1 准确率。

## 5. 第二步：基于标注数据微调 LLM 评估模型

### 5.1 训练目标

使用 1,000 条人工标注数据微调一个 LLM 评估模型，使模型学习人工标注标准，能够根据用户画像、交互序列和候选物品对，自动判断模拟用户的正负样本选择是否合理。

### 5.2 训练方式

1,000 条人工标注数据全部用于微调 LLM 评估模型。

## 6. 第三步：全量自动评估与指标 2

### 6.1 自动评估范围

使用第二步微调得到的 LLM 评估模型，对除 1,000 条人工标注样本之外的剩余模拟数据进行自动评估。

每条样本需要输出：

- LLM 判断的正样本。
- LLM 判断的负样本。
- 模拟用户判断是否正确。

### 6.2 指标 2：自动评估准确率

指标 2 衡量剩余模拟数据在 LLM 评估模型下的准确率。

定义：

```text
指标 2 = 剩余模拟数据中 LLM 判断模拟结果正确的样本数 / 剩余模拟数据总数
```

其中：

- LLM 判断模拟结果正确：LLM 认为模拟用户给出的正负样本判断与用户画像和交互序列一致。
- 剩余模拟数据总数：除 1,000 条人工标注数据之外的模拟数据数量。

目标：

```text
指标 2 >= 75%
```

若指标 2 达到或超过 75%，则认为剩余模拟数据的自动评估准确率满足目标要求。

## 7. 全量模拟数据准确率

最终的全量模拟数据准确率由指标 1 和指标 2 共同组成。若需要给出一个统一数值，可按样本量计算：

```text
全量模拟数据准确率 =
（1,000 * 指标 1 + 剩余模拟数据总数 * 指标 2）
/（1,000 + 剩余模拟数据总数）
```

同时需要分别报告指标 1 和指标 2，避免只看加权结果而忽略人工评估集与自动评估集之间的差异。
